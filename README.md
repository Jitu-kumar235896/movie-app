# 🎬 Movie App

A simple movie search application built using the **OMDb API**.  
Users can search for movies and view basic details like title, year, and poster.

---

## 🚀 Features
- Search movies by name
- Fetch data from OMDb API
- Display movie title, year, and poster
- Responsive UI

---

## 🛠 Tech Stack
- React / Next.js
- Tailwind CSS
- OMDb API
